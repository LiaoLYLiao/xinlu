# 心路 Lite

每天寫一點，累積久了，就看得見自己心裡反覆發生的事。

心路是一個可以加到手機主畫面的日記與心理衛教工具：

- **資料只在你的裝置**：沒有帳號、沒有伺服器、沒有追蹤。日記存在瀏覽器的 IndexedDB，可以匯出備份。
- **用你自己的 AI 整理**：
  1. 複製貼上：把準備好的文字貼到你自己的 ChatGPT、Claude 或 Gemini，再把回覆貼回來。
  2. 自己的 API 金鑰：金鑰只存在你的裝置，直接呼叫 OpenAI、Anthropic 或 Google 的 API。
  3. 心路助手範本：用提供的指示和知識檔，建立你自己的 GPT、Claude 專案或 Gemini Gem。
- **送出前的隱私保護**：記下的人物名字自動換成「人物A」這類代號，可能是名字但還沒記下的字會在送出前提醒，電話、Email、身分證字號、卡號會被遮蔽，每次都能先檢視實際送出的內容。
- **心理衛教**：方法庫（10 類、45 個方法，各附依據）與研究庫，每週更新心理學新知（`weekly.json`）。

心路是自我紀錄與心理衛教工具，不是心理諮商，AI 的整理也不是診斷。
需要幫忙時：安心專線 1925（24 小時）、生命線 1995、張老師 1980，緊急狀況請撥 119 或 110。

## 檔案

- `index.html`：整個應用程式（單一檔案）
- `sw.js`、`manifest.webmanifest`、圖示：讓它可以離線使用、安裝到主畫面
- `weekly.json`：每週心理學新知
